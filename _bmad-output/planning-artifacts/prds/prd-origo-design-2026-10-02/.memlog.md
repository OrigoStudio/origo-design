topic: Origo Design Phase 2 PRD
updated: 2026-10-04T17:56
---

- (decision) Replace AG Grid with in-house custom Origo Grid for Phase 2 based on user request
- (decision) Bring Phase 4 Enterprise & Dynamic Components (PermissionGate, Workflow, DynamicForm, etc.) forward into Phase 2
- (decision) Release Origo UI components as a standalone, independent library that conforms to the Origo Component API Specification, decoupled from but consumed by the Origo BADL declarative engine.
- (decision) Build standalone, versioned documentation for the UI components product, organized by category -> component, including version-specific 'What is new' changelogs.
- (decision) Subdivide large Component Epics (Epic 1 and Epic 2) into smaller logical component batches (e.g., Core Forms, Layouts, DataGrid Foundation, etc.) to ensure stories are granular, well-scoped, and prevent long-running tasks.
